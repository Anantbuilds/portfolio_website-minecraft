# ANDYCRAFT — Developer Portfolio

> No real personal details were supplied in the brief, so the implementation uses clearly marked placeholder portfolio data.

A production-ready React + Vite + TypeScript portfolio with an original pixel-art-inspired world UI.

## Customize

Update **`src/data/portfolio.ts`** to change:
- Name, title, role and bio
- Profile links and email
- Skills and configurable skill levels
- Projects, tech stacks, challenges and results
- Experience and quest rewards
- Achievements
- Resume path

The UI reads from the data file instead of hardcoding portfolio content into sections.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The design intentionally uses original CSS/SVG-style UI primitives rather than game logos or copyrighted game assets.
